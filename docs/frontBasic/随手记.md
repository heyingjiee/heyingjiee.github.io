Conversation中用鼠标选中一句话，按r可在自己的回复里，引用其他的话

![image-20230720100048445](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20230720100048%20.png)



如果是自己的仓库，被提issue，每个issue会有一个`#xxxx`的编号。自己修复后，以下面任意一种格式提交commit message，对应的issue就会被关闭

```
fix #24
fixes #24
fixed #24
close #24
closes #24
closed #24
resolve #24
resolves #24
resolved #24
```
