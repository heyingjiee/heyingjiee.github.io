# 小游戏

## ThreeJS

### 基础

图形编程依赖 OpenGL 提供的 API 操作 GPU ，其版本也在逐步演进的，从 OpenGL 2.0 开始支持**着色器**编程

![image-20250101173743415](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20250101173743ljgPdZ.png)

在 Web 端图形编程依赖：

* WebGL API

  WebGL API 是浏览器提供的 JS 接口，其是基于 OpenGL ES 的封装（OpenGL ES 仅包含OpenGL的部分能力）

* GLSL

  GLSL 是着色器语言（类似于 C 语言），包括顶点着色器（Vertex Shader）、片元着色器 （Fragment Shader）
