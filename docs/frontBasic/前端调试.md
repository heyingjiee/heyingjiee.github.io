## Vue项目

### 3个概念

* npm dev 启动的是开发服务器 。 控制台输出的地址是服务器地址，浏览器访问这个地址返回页面

  ![image-20250221005300883](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20250221005301pPr0Np.png)

* 以远程调试模式启动Chrome ，打开上面地址后 ，浏览器会启动调试的 ws 调试服务

* Chrome devtool、IDEA 开发工具都需要链接 Chrome 启动的调试服务 

  ![image-20250221005538363](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20250221005538xZqmNQ.png)

  ![image-20250221005641711](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/202502210056412uLeTt.png)

⚠️ 调试 npm dev 实际上是调试 Vite ，而不是项目

⚠️ 调试能力是Chrome提供的，IDEA 只是连接了这个调试服务



### IDEA连接调试服务

#### 调试步骤

* 启动 Web 开发服务器 npm dev

* 启动 Chrome 的调试服务 

  * 配置页面

    ![image-20250221011646127](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20250221011646uwwtEl.png)

  * 注意浏览器选项很重要
  
    设置 Chrome 以调试模式启动 （`--remote-debugging-port=9222`，指定调试端口）
  
    设置自定义目录，默认 Chrome 数据目录是`/Users/heyingjie/Library/Application Support/Google/Chrome`，这里我们设置为 `/Users/heyingjie/Library/Application Support/Google/Chrome Dev` 
  
    ![image-20250221010420297](https://hedaodao-1256075778.cos.ap-beijing.myqcloud.com/Essay/20250221010420S1K2QV.png)、
