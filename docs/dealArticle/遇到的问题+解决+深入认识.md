### js中使用||或者&&赋值

[js中使用||或者&&赋值](https://www.cnblogs.com/nana33/p/10272670.html)

几乎所有语言中||和&&都遵循“短路”原理，如&&中第一个表达式为假就不会去处理第二个表达式，而||第一个表达式为真就不会处理第二个表达式。
js也遵循上述原则。但是比较有意思的是它们返回的值。

```js
var attr = true && 4 && “aaa”;
```


运行的结果attr就不是简单的true或这false，而是”aaa”。

用于赋值时的规则：

* &&：从左往右依次判断，当当前值（会转化为布尔值）为true则继续，为false则返回此值（是返回未转换为布尔值时的原值哦）
* || ： 从左往右依次判断，当当前值（会转化为布尔值）为false则继续，为true则返回此值（是返回未转换为布尔值时的原值哦）

注意：0，NaN，""，null，undefined，false(6个)，转化为布尔值时false

总结：&&找假，找到返回假值，找不到返回最后一个真的值。||找真，找到返回真值，找不到返回最后一个假的值。

常用技巧:

```js
//初始化数据，如果a是：0，NaN，""，null，undefined，false则把a赋值为空字符串
var a=a||""
```

### 父组件向子组件传参的问题

* 通过props传递参数后，要改变该参数

  通过props传递到子组件内的参数，要改变该参数，一般需要赋值给新变量，改变新变量，不能直接改变传递进来的数据（Vue禁止子组件改变父组件的数据）

* 通过props传递进子组件的参数，在子组件的data()中赋值给新变量，当prop属性改变时，data中的变量，不能追踪

  ```vue
  props: ['info'],
  data() {
      return {
          list: this.info,
      }
  }
  ```

  https://segmentfault.com/a/1190000012376896

* 既然直接赋值给data的变量行不通，那么通过props传递进子组件的参数一直变化。如何保证新变量跟随一起改变？

  https://www.cnblogs.com/_error/p/9701136.html

  使用watch或computed来监听prop传递进来的参数，当发生变化时，改变新变量

  **例子：**info是prop属性

  ```vue
  //监听info变量，发生变化赋值给list
  watch: {
      info() {
        this.list = this.info
      }
    }
  ```

  ```vue
  //监听info变量，发生变化赋值给list
  computed: {
      list (){
        return this.info
      }
    },
  ```

  **不应该使用箭头函数来定义 watcher 函数** (例如 `searchQuery: newValue => this.updateAutocomplete(newValue)`)。理由是箭头函数绑定了父级作用域的上下文，所以 `this` 将不会按照期望指向 Vue 实例.

* 当使用computed时，改变计算出来的新变量，报错

  https://blog.csdn.net/chenhui88889/article/details/100789666

## PV和UV以及埋点

**UV（Unique visitor）**
是指通过互联网访问、浏览这个网页的自然人。访问您网站的一台电脑客户端为一个访客。00:00-24:00内相同的客户端只被计算一次。

一天内同个访客多次访问仅计算一个UV。

**IP（Internet Protocol）**
独立IP是指访问过某站点的IP总数，以用户的IP地址作为统计依据。00:00-24:00内相同IP地址之被计算一次。

**PV（Page View）**
即页面浏览量或点击量，用户每1次对网站中的每个网页访问均被记录1个PV。用户对同一页面的多次访问，访问量累计，用以衡量网站用户访问的网页数量。

**VV（Visit View）**
用以统计所有访客1天内访问网站的次数。当访客完成所有浏览并最终关掉该网站的所有页面时便完成了一次访问，同一访客1天内可能有多次访问行为，访问次数累计。

****

**UV与IP区别：**
如：你和你的家人用各自的账号在同一台电脑上登录新浪微博，则IP数+1，UV数+2。由于使用的是同一台电脑，所以IP不变，但使用的不同账号，所以UV+2

**PV与VV区别：**
如：你今天10点钟打开了百度，访问了它的三个页面；11点钟又打开了百度，访问了它的两个页面，则PV数+5，VV数+2.
PV是指页面的浏览次数，VV是指你访问网站的次数。

## UUID

生成唯一不重复的编码

百度百科https://baike.baidu.com/item/UUID/5921266?fr=aladdin

```js
/*
 生成UUID
 @para len {Number} 长度
 @para radix {Number} 算法基数
 @return uuid{String} 生成的UUID
 */
function createUUID (len, radix) {
    var chars = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz'.split('');
    var uuid = [],
        i;
    radix = radix || chars.length;

    if (len) {
        // Compact form
        for (i = 0; i < len; i++) uuid[i] = chars[0 | Math.random() * radix];
    } else {
        // rfc4122, version 4 form
        var r;

        // rfc4122 requires these characters
        uuid[8] = uuid[13] = uuid[18] = uuid[23] = '-';
        uuid[14] = '4';

        // Fill in random data.  At i==19 set the high bits of clock sequence as
        // per rfc4122, sec. 4.1.5
        for (i = 0; i < 36; i++) {
            if (!uuid[i]) {
                r = 0 | Math.random() * 16;
                uuid[i] = chars[(i == 19) ? (r & 0x3) | 0x8 : r];
            }
        }
    }
    return uuid.join('');
}
```
